# 公司职员管理系统

使用抽象员工基类和多态实现总经理、技术经理、技术人员、销售经理、销售人员。支持录入、显示、按编号查询、修改、删除和月薪总额统计。销售经理的提成按所有销售人员当月销售总额的 5‰ 计算，销售人员按个人销售额的 1% 计算。

程序使用 `Role` 枚举统一表示职位，并通过 `EmployeeFactory` 创建具体员工对象，避免主菜单中堆叠职位判断。员工数据会保存到可执行文件所在目录的 `employees.dat`，因此从其他工作目录启动也会使用同一份数据；姓名支持空格并可以正常持久化。奖金、销售额等金额必须是非负有限数字。

查询功能支持按编号、姓名、职位和级别筛选员工。新员工从 1 级开始，管理员可通过菜单 8 按编号将其提升至职位规定等级。晋升后保存当前等级，重启后仍可恢复。读取旧版三列数据时，旧员工沿用原先按职位确定的等级。

程序启动后需要登录：

- 管理员：用户名 `admin`，密码 `admin`。可以录入、显示、查询、修改、删除、晋升级别、统计员工，并查看操作日志。
- 普通用户：用户名 `user`，密码 `user`。只能显示、查询和统计员工，不能修改数据。

管理员的登录结果以及新增、修改、删除等操作会追加保存到可执行文件所在目录的
`employee_operations.log`，日志中不保存密码。

```bash
g++ -std=c++17 -Wall -Wextra -pedantic employee_system.cpp -o employee_system
./employee_system
```

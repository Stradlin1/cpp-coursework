# 无符号大整数计算器

第二题的独立实现。数字以字符串保存，不受 C++ 内置整数类型位数限制，支持：

- 加法、减法、乘法的精确计算；
- 使用十进制长除法实现精确商和余数，支持 `/` 与 `%`；
- 减法结果为负数时显示负号；
- 除法结果以两位有效数字的科学计数法显示，例如 `1.2e+19`；
- 连续输入表达式，输入 `q` 或 `Q` 退出；
- 除数为零和非法输入检查。

## 编译运行

```bash
g++ -std=c++17 -Wall -Wextra -pedantic calculator.cpp -o calculator
./calculator
```
